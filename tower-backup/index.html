Private backup application

Tower Kopia Backup

A privately operated backup application that uses Kopia and Rclone to maintain encrypted backups of selected personal files in the owner’s Google Drive storage.

Read the privacy policy

How backups work

Kopia encrypts backup contents locally before upload. Incremental snapshots record changes over time, while content deduplication avoids storing repeated content unnecessarily.

Google Drive access

Google OAuth authorizes Rclone to access the owner’s Google Drive account within the granted scope. This access supports creating, maintaining, verifying, and restoring encrypted personal backups.

For personal use only

This application is intended for the owner’s personal use. It is not offered as a public service, and this website does not provide access to the backup application.
